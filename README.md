# AI Usage & Impact Analysis

## Project Overview

This project explores how students and professionals use Artificial Intelligence (AI) tools and examines their impact on productivity, work efficiency, and daily activities.

The objective is to analyse AI usage patterns, understand user behaviour, and identify meaningful insights from the dataset using Excel and data analysis techniques.

## Dataset Description

The dataset, `AI_Usage_and_Impact_on_Students_and_Professionals.csv`, contains information about AI usage among students and professionals.

It includes details such as:
- User information (age, gender, country)
- AI tools and their purposes
- Productivity scores
- AI usage patterns and related metrics

### 2. Data Analysis Using Excel

Added two new calculated columns to the dataset using Excel's logical functions:

- **IF Function:** Created an `Accuracy_Status` column to classify performance into Low Performer and High Performer based on the accuracy value.

  Formula:
  `=IF(O2<=3,"Low Performer","High Performer")`

- **IFS Function:** Added another calculated column using the IFS function to apply multiple logical conditions and categorise the data accordingly.
